# Vuelta al Mundo

Juego de mesa multijugador privado, inspirado en los clásicos de compraventa de propiedades. Incluye sala por enlace, tablero de 40 casillas, turnos, dados, propiedades, renta, cárcel, eventos, impuestos y bancarrota.

## Ejecutar

```bash
npm install
npm start
```

Abre `http://localhost:3001`. Para compartirlo fuera de tu red local hay que desplegar el servidor en un servicio compatible con Node.js y WebSockets (por ejemplo Render, Railway o Fly.io).
